# Анимации войны на карте (Remotion)

Карта строится из исходной картинки `public/map.png`. В проекте две композиции.

## Rebellion — основной ролик (46 с, 1920×1080, со звуком)

Готовое видео: [rebellion-preview.mp4](rebellion-preview.mp4).

На экране нет надписей: только карта, войска и численность каждой группы прямо у линии фронта.

1. Красные бьют по синим тремя стрелками.
2. На юге красных поднимается восстание **зелёных повстанцев**: три очага, один за другим.
3. Синие контратакуют, отбивают свою землю и заходят на территорию красных.
4. Повстанцы расширяются на север, синие идут вглубь, окружённые котлы схлопываются.
5. Последние очаги красных добивают. **Красные проигрывают**, карту делят синие и зелёные.

Стрелки растут вместе с фронтом, а после операции втягиваются и исчезают. Войска показаны
точками, их число зависит от численности. Когда армию окружают, она гибнет со взрывом,
а счётчик бойцов уходит в ноль.

Звук синтезируется кодом, без чужих сэмплов: взрывы, очереди, артподготовка, свист стрелок,
военный барабан, гул боя и тёмная музыкальная подложка. Скрипт считает фронты тем же
движком, что и видео, поэтому каждый звук попадает в свой кадр.

## WarMap — первый ролик (37 с)

Красные наступают на синих и побеждают. В ролике есть интерфейс, названия армий и баннер победы.
Готовое видео: [preview.mp4](preview.mp4).

## Запуск

```bash
cd war-animation
npm install
npm run dev            # Remotion Studio — предпросмотр
npm run render         # Rebellion → out/rebellion.mp4
npm run render:first   # WarMap → out/war.mp4
npm run sound          # пересобрать звук после изменения сценария
```

## Как устроено

- `src/lib/terrain.ts`: распознавание суши и сторон по цвету картинки, шум, Дейкстра по пикселям.
- `src/rebellion/scenario.ts`: **сценарий**. Здесь операции (кто наступает, на кого, когда,
  район, стрелки), армии (где стоят, по каким стрелкам идут, численность по кадрам) и камера.
- `src/rebellion/engine.ts`: для каждой операции считает «время захвата» каждого пикселя.
  Скорость зависит от шума (фронт рваный) и от стрелок (вдоль них фронт идёт быстрее).
  Результат — история смены хозяина у каждого пикселя. Здесь же котлы, гибель армий и вспышки боёв.
- `src/rebellion/WarCanvas.tsx`: отрисовка территорий; `WarOverlay.tsx`: стрелки, войска и численность, взрывы.
- `scripts/sound.ts` и `scripts/synth.ts`: генерация `public/audio/rebellion.mp3`.
- `src/world.ts`, `src/plan.ts`, `src/timeline.ts`, `src/Hud.tsx`: первый ролик.

Шрифты (Roboto Condensed, Russo One) берутся из пакетов `@fontsource`, поэтому рендер работает без сети.
