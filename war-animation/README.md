# Война за континент — анимация на Remotion

Анимация захвата территории: **красные** наступают тремя армиями и побеждают **синих**.
Карта строится из исходной картинки `public/map.png`.

Готовое видео: [preview.mp4](preview.mp4).

## Что в ролике (37 с, 1920×1080, 30 fps)

1. **Интро.** Заголовок «Война за континент».
2. **Развёртывание.** Войска (точки) появляются, армии красных выдвигаются из тыла к фронту.
3. **План ударов.** Пунктиром прорисовываются направления трёх армий, к ним «вырастают» стрелки.
4. **Наступление.** Фронт рваной «горящей» линией ползёт на восток. Занятая земля заштрихована.
   Точки красных идут за фронтом, синие точки отходят и уничтожаются (вспышка и «✕»), по линии фронта видны разрывы.
5. **Контрудар синих.** Синяя стрелка бьёт навстречу, её отбивают, и начинается прорыв. Позади фронта остаются котлы.
6. **Морские десанты** на острова.
7. **Победа красных.** Синие капитулируют, территория под контролем красных — 100%.

В HUD показаны день операции, фаза, войска, территория и дивизии каждой стороны, а также полоса контроля территории.

## Запуск

```bash
cd war-animation
npm install
npm run dev      # Remotion Studio — предпросмотр в браузере
npm run render   # рендер в out/war.mp4
```

## Как это устроено

- `src/world.ts`: читает пиксели карты и определяет сушу, красных и синих. Затем алгоритмом
  Дейкстры по пиксельной сетке считает для каждого пикселя «время захвата». Скорость
  продвижения задаётся шумом (поэтому фронт рваный) и коридорами главных ударов
  (поэтому фронт выгибается вдоль стрелок). Через море фронт идёт медленно, так что острова
  берутся последними, десантами.
- `src/timeline.ts`: тайминги и темп наступления (разгон, затишье во время контрудара, прорыв).
- `src/plan.ts`: оси ударов армий, десанты и контрудар в координатах картинки 1536×1024.
  Чтобы поменять сценарий, правьте этот файл.
- `src/MapCanvas.tsx`: попиксельная отрисовка территорий на canvas.
- `src/Overlay.tsx`: стрелки, войска-точки, вспышки боёв (SVG).
- `src/Hud.tsx`: интерфейс, интро и баннер победы.

Шрифты (Russo One, Roboto Condensed) берутся из пакетов `@fontsource`, поэтому рендер работает без сети.
